# Better File Properties View

This plugin enhances Obsidian's file properties view by adding the following features:

- Displays a thumbnail using a configurable property name
- Optionally Hides metadata container if File Properties is active

## Usage

Simply install and enable the plugin. You can access plugin configurations
in Obsidian settings.

## Build

You can build this project using the following commands:

```
npm i
npm run build
```
